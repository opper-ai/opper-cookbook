# Legacy Examples

These examples target older versions of the Opper SDK (`opperai` versions before 2.0). They remain here for reference but are no longer actively maintained.

For new projects, use the **current examples** in the parent `examples/` directory, which use the latest Opper SDK.

## Examples

| Example | Description |
|---------|-------------|
| bootstrap | Interactive CLI for bootstrapping training examples |
| caching | Response caching capabilities |
| chat-with-feedback | Chat loop with user feedback and in-context learning |
| deep-research-w-langraph | Multi-stage research pipeline with LangGraph |
| gsm8k-cot | Chain-of-thought reasoning on GSM8K |
| in-context-learning | Model router using in-context learning |
| intro-to-multimodal | Introduction to multimodal capabilities |
| mistral-rag | RAG with Mistral |
| poker-tournament | AI poker game with personality and memory |
| rag-answer-correctness | RAG answer correctness evaluation |
| rag-with-o1 | RAG with OpenAI o1 |
| reference-free-eval | Evaluation without reference answers |
| tictactoe-learning | Tic Tac Toe AI that learns from games |
| tictactoe-tournament | Tournament-style Tic Tac Toe |
